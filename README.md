# AlexxGrekk Engineering Standard

Единый стандарт разработки для проектов AlexxGrekk.

Обязательный цикл: **Issue → feature branch → implementation → tests → Pull Request → review → manual merge → close Issue → update `PROJECT_STATE.md`**.

Auto Merge не используется и не включается.
