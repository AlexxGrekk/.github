# Project Maturity Model

## M0 — Foundation

Vision, scope, repository, baseline documentation и `PROJECT_STATE.md` существуют.

## M1 — Playable / Usable Slice

Есть минимальный проверяемый пользовательский результат, Issue, branch, PR, tests и acceptance review.

## M2 — Reliable Product

Основные сценарии покрыты проверками, архитектура документирована, повторяемый CI работает.

## M3 — Operationally Ready

Есть release procedure, rollback/incident guidance, наблюдаемость и подтверждённый эксплуатационный контур.

## M4 — Governed Ecosystem

Стандарт применяется across projects, milestones имеют evidence, а состояние обновляется после каждого merge.

Переход между уровнями — отдельный milestone с Issue, критериями и review; открытый PR уровень зрелости не меняет.
