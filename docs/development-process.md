# SDLC

```text
Vision → Architecture → Backlog → Issue → Feature branch → Implementation
→ Tests → Pull Request → Review → User acceptance → Manual merge
→ Close Issue → Update PROJECT_STATE.md → Release
```

Issue — единица планирования и критериев приемки. Ветка и PR однозначно связаны с Issue. Открытый PR не является завершением работы.
