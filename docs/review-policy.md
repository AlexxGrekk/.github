# Review Policy

Review состоит из technical review (корректность, тесты, безопасность, архитектура, документация) и acceptance review (соответствие Issue, Vision, roadmap и принятым решениям).

После устранения замечаний пользователь принимает результат. Только затем выполняется ручной merge. Auto Merge запрещён; Issue закрывается после merge и обновления `PROJECT_STATE.md`.
