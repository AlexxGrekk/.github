# AI Agent Rules

- Не начинать содержательную реализацию без Issue.
- Исследовать текущие контракты и изменять минимальный необходимый scope.
- Не выдумывать несовместимые контракты и не подменять требуемые реальные проверки моками.
- Выполнять проверки и сообщать фактические результаты.
- Поддерживать связь Issue → branch → PR.
- Не выполнять merge без явного принятия пользователем.
- Не включать и не использовать Auto Merge.
- После каждого merge обновлять `PROJECT_STATE.md`.
- При неопределённости фиксировать ограничение и запрашивать решение.
