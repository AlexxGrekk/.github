# Contributing

1. Создать Issue с целью, критериями приемки и ограничениями.
2. Создать одну ветку от актуального `main`.
3. Реализовать изменение проверяемыми коммитами.
4. Запустить тесты и обновить документацию.
5. Открыть один PR, связанный с Issue.
6. Провести technical и acceptance review.
7. После явного принятия выполнить **ручной merge**.
8. После merge обновить `PROJECT_STATE.md` и закрыть Issue.

Работа не завершена по факту открытия PR. Auto Merge запрещён.

## Definition of Done

- критерии Issue выполнены;
- проверки пройдены или ограничения описаны;
- документация синхронизирована;
- PR reviewed и принят пользователем;
- выполнен ручной merge;
- `PROJECT_STATE.md` обновлён после merge;
- связанный Issue закрыт.

Коммиты: Conventional Commits — `feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `ci:`, `chore:`.
